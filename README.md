# Nature – BioDex MMO

Prototyp eines Natur-Foto-Spiels: Tiere und Pflanzen fotografieren, per (simulierter) KI bestimmen, im Natur-Kodex sammeln, Medaillen freischalten und Funde anderer Spieler im Community-Hub bestätigen.

## Features

- **Dashboard** mit Saison-Challenge, Statistiken und letzten Entdeckungen
- **Foto-Scanner** (Mockup) mit Test-Motiven und Punkteberechnung
- **Natur-Kodex** mit Filtern (Vögel, Insekten, Säugetiere, Pflanzen, Nachtaktiv)
- **Forscher-Koffer & Medaillen**
- **MMO Hub** zur Bestätigung von Funden

## Technik

Einzelne statische Seite (`index.html`), ohne Build-Schritt:

- Tailwind CSS (CDN)
- Font Awesome (CDN)
- Vanilla JavaScript

## Lokal starten

`index.html` einfach im Browser öffnen.

## GitHub Pages

Unter *Settings → Pages* den Branch `main` und den Ordner `/ (root)` auswählen.
